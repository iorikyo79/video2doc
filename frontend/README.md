# Video2Doc Frontend MVP

🎬 **간단하고 직관적인 웹 인터페이스**로 Video2Doc 백엔드를 사용할 수 있습니다.

## 🧪 Mock 모드 지원

개발 단계에서 백엔드 없이도 프론트엔드를 테스트할 수 있는 Mock 모드를 지원합니다.

### Mock 모드 특징
- ✅ **백엔드 의존성 없음**: Video2Doc 백엔드 설치 없이 UI 테스트 가능
- ✅ **빠른 응답**: 1-3초 내 가짜 보고서 생성
- ✅ **완전한 워크플로우**: 실제와 동일한 UI/UX 플로우
- ✅ **다양한 테스트**: 모든 옵션 조합 테스트 가능
- ⚠️ **실제 분석 없음**: 업로드된 콘텐츠는 실제로 분석되지 않음

### Mock 모드 사용법
1. 사이드바에서 "🧪 Mock 모드 (개발용)" 체크박스 활성화
2. 일반적인 워크플로우와 동일하게 사용
3. 샘플 보고서가 빠르게 생성됨

## 🚀 빠른 시작

### 1. 요구사항
- Python 3.8+
- Video2Doc 백엔드 (실제 모드 사용 시에만 필요)

### 2. 설치
```bash
# 프로젝트 루트에서 실행
cd frontend
pip install -r requirements.txt
```

### 3. 실행
```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 자동으로 열립니다.

### 4. 개발 모드 (Mock)
- 사이드바에서 Mock 모드 활성화
- 백엔드 설치 없이 UI 테스트 가능
- 샘플 데이터로 전체 워크플로우 확인

## 📋 기능

### ✅ 지원하는 입력
- **오디오/비디오 파일**: MP4, MP3, AVI, MOV, MKV, WAV, M4A
- **YouTube URL**: 모든 공개 YouTube 비디오
- **참조 문서**: PDF, PowerPoint, Word, Excel, 이미지, 텍스트

### ⚙️ 설정 옵션
- **보고서 유형**: 요약 / 상세 분석 / 프레젠테이션
- **보고서 길이**: 짧게 / 중간 / 길게
- **AI 모델**: 기본 / Qwen / DeepSeek / GPT-4

### 📊 실시간 진행률
- YouTube 다운로드 진행률
- 오디오 추출 및 음성 인식 진행률
- 문서 생성 진행률

### 🧪 개발자 기능
- **Mock 모드**: 백엔드 없이 UI 테스트
- **실시간 모드 전환**: 사이드바에서 즉시 전환
- **샘플 데이터**: 다양한 시나리오 테스트 가능

## 🎯 사용법

### 1단계: 소스 선택
- **파일 업로드**: 드래그 앤 드롭 또는 파일 선택
- **YouTube URL**: URL 붙여넣기 후 비디오 정보 확인

### 2단계: 참조 파일 (선택사항)
- 관련 문서들을 추가로 업로드
- 여러 파일 동시 선택 가능

### 3단계: 옵션 설정
- 보고서 유형, 길이, AI 모델 선택
- 기본값으로도 충분히 좋은 결과

### 4단계: 문서 생성
- "문서 생성 시작" (실제 모드) 또는 "Mock 문서 생성" (Mock 모드) 버튼 클릭
- 실시간 진행률 확인
- 완료 후 마크다운 파일 다운로드

## 📁 출력 파일

생성된 파일들은 `output/` (실제 모드) 또는 `mock_output/` (Mock 모드) 디렉토리에 저장됩니다:

```
output/
├── 01_youtube_VIDEO_ID_title.mp4     # YouTube 다운로드 (URL 입력 시)
├── 02_filename.mp3                   # 추출된 오디오
├── 03_filename_script.md             # 음성인식 스크립트
├── 04_reference_file.md              # 변환된 참조 문서
├── 05_filename_full_context.md       # 통합 컨텍스트
└── 06_filename_summary_mid.md        # 최종 보고서 ⭐
```

Mock 모드에서는 `mock_output/` 디렉토리에 샘플 보고서만 생성됩니다.

## 🔧 문제 해결

### 일반적인 문제들

#### 1. "백엔드 모듈을 찾을 수 없습니다"
**해결방법 1: Mock 모드 사용**
- 사이드바에서 "Mock 모드" 체크박스 활성화
- 백엔드 없이 UI 테스트 가능

**해결방법 2: 백엔드 설치**
```bash
# frontend 디렉토리가 video2doc 프로젝트 루트에 있는지 확인
video2doc/
├── frontend/          # 여기에 있어야 함
│   ├── app.py
│   └── requirements.txt
├── core/
├── processors/
└── ...
```

#### 2. YouTube 다운로드 실패
- 인터넷 연결 확인
- YouTube URL이 공개 비디오인지 확인
- VPN 사용 시 비활성화 시도
- Mock 모드에서는 실제 다운로드 없이 시뮬레이션

#### 3. 처리 시간이 너무 오래 걸림
- 더 짧은 동영상으로 시도
- 참조 파일 수 줄이기
- 로컬 모델 대신 더 빠른 모델 선택
- 개발 중에는 Mock 모드 사용 (1-3초)

#### 4. 메모리 부족 오류
- 더 작은 파일로 시도
- 다른 프로그램 종료
- GPU 메모리 확인 (CUDA 사용 시)
- Mock 모드는 메모리 사용량 최소

#### 5. 개발 중 빠른 테스트가 필요한 경우
- Mock 모드 활성화
- 다양한 UI 시나리오 빠르게 테스트
- 실제 백엔드 설정 없이 데모 가능

### 로그 확인
- **실제 모드**: `output/video2doc.log` 파일에서 상세 오류 확인
- **Mock 모드**: 브라우저 콘솔에서 오류 확인

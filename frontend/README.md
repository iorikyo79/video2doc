# Video2Doc Frontend MVP

🎬 **간단하고 직관적인 웹 인터페이스**로 Video2Doc 백엔드를 사용할 수 있습니다.

## 🚀 빠른 시작

### 1. 요구사항
- Python 3.8+
- Video2Doc 백엔드가 설치되어 있어야 함

### 2. 설치
```bash
# 프로젝트 루트에서 실행
cd frontend
pip install -r requirements.txt
```

### 3. 실행
```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 자동으로 열립니다.

## 📋 기능

### ✅ 지원하는 입력
- **오디오/비디오 파일**: MP4, MP3, AVI, MOV, MKV, WAV, M4A
- **YouTube URL**: 모든 공개 YouTube 비디오
- **참조 문서**: PDF, PowerPoint, Word, Excel, 이미지, 텍스트

### ⚙️ 설정 옵션
- **보고서 유형**: 요약 / 상세 분석 / 프레젠테이션
- **보고서 길이**: 짧게 / 중간 / 길게
- **AI 모델**: 기본 / Qwen / DeepSeek / GPT-4

### 📊 실시간 진행률
- YouTube 다운로드 진행률
- 오디오 추출 및 음성 인식 진행률
- 문서 생성 진행률

## 🎯 사용법

### 1단계: 소스 선택
- **파일 업로드**: 드래그 앤 드롭 또는 파일 선택
- **YouTube URL**: URL 붙여넣기 후 비디오 정보 확인

### 2단계: 참조 파일 (선택사항)
- 관련 문서들을 추가로 업로드
- 여러 파일 동시 선택 가능

### 3단계: 옵션 설정
- 보고서 유형, 길이, AI 모델 선택
- 기본값으로도 충분히 좋은 결과

### 4단계: 문서 생성
- "문서 생성 시작" 버튼 클릭
- 실시간 진행률 확인
- 완료 후 마크다운 파일 다운로드

## 📁 출력 파일

생성된 파일들은 `output/` 디렉토리에 저장됩니다:

```
output/
├── 01_youtube_VIDEO_ID_title.mp4     # YouTube 다운로드 (URL 입력 시)
├── 02_filename.mp3                   # 추출된 오디오
├── 03_filename_script.md             # 음성인식 스크립트
├── 04_reference_file.md              # 변환된 참조 문서
├── 05_filename_full_context.md       # 통합 컨텍스트
└── 06_filename_summary_mid.md        # 최종 보고서 ⭐
```

## 🔧 문제 해결

### 일반적인 문제들

#### 1. "백엔드 모듈을 찾을 수 없습니다"
```bash
# frontend 디렉토리가 video2doc 프로젝트 루트에 있는지 확인
video2doc/
├── frontend/          # 여기에 있어야 함
│   ├── app.py
│   └── requirements.txt
├── core/
├── processors/
└── ...
```

#### 2. YouTube 다운로드 실패
- 인터넷 연결 확인
- YouTube URL이 공개 비디오인지 확인
- VPN 사용 시 비활성화 시도

#### 3. 처리 시간이 너무 오래 걸림
- 더 짧은 동영상으로 시도
- 참조 파일 수 줄이기
- 로컬 모델 대신 더 빠른 모델 선택

#### 4. 메모리 부족 오류
- 더 작은 파일로 시도
- 다른 프로그램 종료
- GPU 메모리 확인 (CUDA 사용 시)

### 로그 확인
상세한 오류 정보는 `output/video2doc.log` 파일에서 확인할 수 있습니다.
